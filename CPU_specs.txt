### Key

M = RAM[A]
A = Register A

Load = RAM to Register
Store = Register to RAM


Uses RGB565 for screen colors -> 16 bits each RGB sequence = 20 * 20 * 16 = 6,400 bits total for a screen size of 20x20
Need RAM size of 512x16, use remaining addresses are reserved space -> Address Bit Width = 9, Data Bit Width = 16


### Example Instructions for Busses

Address Bus	---> 1010010010101110	# Locate Address 0xA4AE
Data Bus	---> 1001010110101000	# Write 38312 to Address 0xA4AE
Control Bus	---> 10					# WRITE, READ


### Some Functions for Assembly

DB {VAR_NAME}, {VALUE}		---> Defines a byte {VAR_NAME} with value {VALUE} in memory
MOV {DST}, {SRC}		---> Moves a byte from {SRC} to {DST}
[{VAR_NAME}]			---> Accesses the content of the memory address where {VAR_NAME} is stored
ADD {REG_NAME}, {REG_NAME}	---> Adds two variables at a certain register

	| `jjj` | Jump condition         |
	| ----- | ---------------------- |
	| `000` | Never jump             |
	| `001` | Jump if ALU output > 0 |
	| `010` | Jump if ALU output = 0 |
	| `011` | Jump if ALU output ≥ 0 |
	| `100` | Jump if ALU output < 0 |
	| `101` | Jump if ALU output ≠ 0 |
	| `110` | Jump if ALU output ≤ 0 |
	| `111` | Always jump            |
